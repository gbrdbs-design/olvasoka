# Olvasóka

Vidám magyar olvasójáték gyerekeknek, három 25 szavas szinttel, kép felfedésével és csillagjutalmakkal.

- SPACE vagy a gomb: kép felfedése, majd következő szó.
- Öt szavanként egy csillag; automatikus szintváltás.
- Az index.html önálló fájl, internet nélkül is megnyitható.

A játék minden rajzot és a logót is beágyazva tartalmazza. Nincs szükség telepítésre vagy buildre.
